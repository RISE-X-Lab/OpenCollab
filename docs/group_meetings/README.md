# Group Meeting Documents

This directory stores meeting-ready OpenCollab research notes. Each meeting gets one dated folder:

```text
docs/group_meetings/YYYY-MM-DD-topic/
```

Each folder should keep the LaTeX source, compiled PDF, and local artifacts needed to reproduce the document. For SWE-bench work, include the current run directory, monitoring files, official-eval report paths, and the exact status of generated patches.
