Topology research · SDK entry

A shared call surface for topology experiments

Construct OpenCollab once, then choose the baseline, a dynamic Team, or a programmed Workflow. Every run returns RunResult.

CHANGE agent · team · workflow

ONE TASK / THREE CONTROL CONDITIONS same observation envelope 
from opencollab import OpenCollab, workflow

# The researcher defines the workflow directly.
@workflow
async def protocol(ctx, inputs):
  draft = await ctx.agent(f"Implement: {inputs['task']}")
  return await ctx.agent(f"Review and correct: {draft}")

oc = OpenCollab(".")
task = "Fix the target defect and verify it"

baseline = await oc.agent(task)
emergent = await oc.team(
  task, config="configs/team.yaml"
)
programmed = await oc.workflow(
  protocol, {"task": task}
)

# baseline / emergent / programmed are all RunResult values.
