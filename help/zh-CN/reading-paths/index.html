刚接触 OC

从零开始：了解概念，装好，跑通第一个任务，看懂结果。

先认识 Agent、Session、Team 和 Workflow → 我该用默认 CLI、Base、Team 还是 Workflow → 安装 OpenCollab → 在自己的项目中完成第一次运行 → 在终端里和 Agent 对话，以及命令参数该写在哪 → 读取运行结果与判断任务是否完成

设计新的 Workflow

想用 Python 写自己的协作流程。

工作流就是普通 Python：编程模型入门 → 工作流能做什么、不能做什么 → 编写第一个自定义 Workflow → Workflow 公开 API 速查 → Workflow 里的数据怎么传：输入、步骤结果、文件与输出 → 在 Workflow 中调用 Agent：ctx.agent 与 ctx.agent_run → 在 Workflow 中并行处理多项任务 → Agent、Team 和 Workflow 怎么互相调用 → 复用子 Workflow，并在候选环境里试改动 → Workflow 出错了：失败、重试与恢复 → 测试和调试你写的 Workflow

建立团队并派发任务

想让多个 Agent 分工合作。

Team 入门：配置你的多 Agent 团队 → 派发 Agent 任务并安排审阅 → 向队友发消息并继续协作 → 等待队友结果并读懂团队状态 → 采用队友改动并验证交付 → 让 Team 成员调用已注册的 Workflow → 让成员自己写并运行子 Workflow

理解与配置隔离

想让 Agent 在独立目录或容器里干活。

隔离怎么选 → 默认隔离与单次覆盖怎么配 → 让多个任务在独立工作区改代码 → 在容器中运行任务 → 在现有 Linux VM 中运行任务 → 让任务在指定目录或现有容器里执行 → 把候选结果采纳到交付目录 → 找回隔离任务的改动并清理资源

配置模型与运行参数

想接入自己的模型服务，或者搞清楚某个配置为什么没生效。

配置从哪里读取以及哪一项生效 → 配置参数与环境变量速查 → 接入模型端点与认证凭据 → 选择调用协议与流式响应 → 配置深度思考与采样参数 → 检查生效配置与排查启动故障

接入自己的应用服务

想在自己的 Python 程序或后台服务里调用 OC。

从 Python 调用 OpenCollab → 接入模型端点与认证凭据 → 逻辑模型路由与共享请求容量 → 把 OpenCollab 接进自己的服务 → 停止任务并确认清理完成 → 查看 Agent 做了什么 → 找到运行记录、会话和交付文件

理解原理与架构

想知道 OC 内部是怎么运转的。

一次任务是怎么跑起来的 → Session 怎样保存进度和继续执行 → 工作流就是普通 Python：编程模型入门 → 工作流能做什么、不能做什么 → 隔离怎么选 → OpenCollab 管什么，我的需求该从哪里扩展 → 检查团队是否真的按分工协作 → 用实际测试验证 Agent 的交付

让每个成员编写并运行自己的 DW

先在 隔离指南 选择成员执行环境，按 VM 指南 准备资源。随后阅读 成员自编 Workflow，完成能力查询、源码生成、并发启动和结果回收。用 共享请求容量 协调模型额度，按 团队通信 把结论发回队友。
