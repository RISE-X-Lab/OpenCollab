OpenCollab Wiki

OpenCollab（OC）是一个让 AI Agent 读代码、改代码、跑命令的框架。你可以只用一个 Agent；也可以让几个 Agent 组成团队，由模型自己分工（Team）；还可以用 Python 代码把协作步骤写清楚（Workflow）。

本 Wiki 按 main 分支提交 0c47f74a 的源码核对。这份源码的包版本号仍是 0.9.5；要用 VM 隔离，或让成员用 manage_workflow describe 查询可用能力，请按 安装指南 安装这个提交。

一张图看懂 OC

OC 的所有设置，都能放进下面这张图：

  1. 每个会话 = 模型 + 工具 + 执行环境 + 限额。 会话（Session）是一个 Agent 的一次“思考 → 调用工具 → 看结果”循环。
  2. 一次运行 = 若干会话 + 一种组织方式。 组织方式回答“下一步由谁决定”：单 Agent、Team（模型决定）或 Workflow（代码决定）。
  3. 交付 = 采纳改动 + 用证据确认做对了。 隔离环境里的改动要显式采纳；completed 不等于做对，要看真正执行过的测试。

上手使用

指南 读完你能做到
安装并完成第一次运行 装好 OC、接上模型，在自己的项目上跑通第一个任务
在终端里使用 OC 切换成员、追问、保存和中断，把参数写在正确的命令层级
从 Python 调用 OC 用 SDK 运行单 Agent、Team 和 Workflow，理解 Base 与 Single2

Team：让模型分工

指南 读完你能做到
Team 入门：用 team.yaml 组织多个 Agent 写出角色、工具和拓扑，选按需成员或固定名册，设置团队预算
Team 协作：派发、消息、等待与采纳 看懂并用好派活、沟通、等结果、收改动这个完整循环

Workflow：用代码编排

指南 读完你能做到
运行一个 Workflow 找到一个 Workflow，交给它任务，读懂结果
编写 Workflow：普通 Python 加上 ctx 写出第一个可按名称运行的 Workflow，知道 OC 能做和不能做什么
在 Workflow 里调用 Agent：会话、数据传递与并行 在步骤之间传数据、拿结构化结果、批量并行
组合与嵌套：子流程、候选环境与互相调用 复用子流程，在候选环境里试改动再采纳，理解嵌套时的预算和停止
Workflow 的失败处理、测试与调试 认出各层失败、安全重试，不花模型额度先测控制流
Workflow API 速查 先找对控制层，再查到具体的参数和接口
让 Team 成员运行 Workflow 用 run_workflow 跑已注册的流程，用 manage_workflow 让成员现场编排子 Workflow
Duo：让两个 coder 各写一版，再挑一个 用内置 Duo 比较两份完整实现并采纳一份
Weave：分组接力完成任务，用检查命令判定交付 把任务拆成有依赖的组，用真实检查判定交付并有限修复
Reconstruct：从输入输出反推一个程序 接入隐藏程序和执行器，让 Agent 重建行为相同的代码

指南 读完你能做到
接入模型服务：端点、凭据、协议与流式 接上 OpenAI 兼容或原生 Anthropic 服务，弄清用哪个 API key
深度思考与采样参数 开关深度思考、设置推理强度和采样参数
模型路由与共享请求容量 让不同角色用不同服务，限制同机并发请求数
配置从哪来、哪个生效、出错怎么查 弄清配置的优先顺序，按阶段排查启动故障
配置参数速查 一张表查清每个配置项的名字、默认值和位置

工具与扩展

指南 读完你能做到
内置工具：怎么选、文件怎么改、命令怎么跑 挑选和限制工具，理解文件编辑和命令执行的安全边界
自定义工具：把你的函数交给 Agent 调用 把业务函数接成工具，并在 Agent 所在环境里操作
Skill：按需加载的说明书 写 SKILL.md，让模型按需加载操作说明
Hook：在工具调用和成员生命周期里运行命令 在工具前后、成员启停时运行观察命令

执行环境与隔离

指南 读完你能做到
隔离：Agent 的文件和命令落在哪里 在六种策略里挑一种，弄清在哪设置、谁优先、工作树从哪开始
在容器中运行任务 让工具在 Docker 里执行，设置镜像、网络和资源上限
在现有 Linux VM 中运行任务 准备来宾、写 VM 配置，运行后导出改动并重置机器
使用自己的执行环境 把现成的目录、容器或 VM 交给 SDK，或注册新的隔离策略
隔离改动怎样回到项目：采纳、找回与清理 采纳候选；出问题时先保住改动再清理资源

预算、步数与并发 设置三个限额旋钮，理解团队分额度和软额度
运行怎样停下：超时、重试、取消与清理 找到卡在哪一层，停止后确认清理完成
上下文窗口与自动压缩 确认窗口、调整压缩策略、排查溢出
